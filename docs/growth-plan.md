# 诸天万界DSH 增长作战计划

> 定稿 2026-08-20。基线：GitHub **1 star** / 0 fork / 0 issue。
> 生态情报：awesome-dsh-plugin 目录 1306 条、13 个分类，**没有文学 / 文字冒险分类**；同类目只有写作板、会话历史、学术写作工具。我们是「一个会话 = 一本书」网文引擎的独一份——**目录红海，题材蓝海**。

## 总战略

一句话卖点：**「在 DeepSeek Harness 里活成一本网文主角」**。

打法四段：**产品先硬 → 货架铺满 → 内容引爆 → 社区飞轮**。
北极星指标：GitHub stars（1 → 50 → 200）。
红线不破：两套文案不混用；不改仓库名；不开空壳 PR；不承诺安全隔离；不提交用户书稿。

## 第一阶段：产品硬核（0.4.14，一周内）

先硬后吹的逻辑：任何一波流量进来，用户第一件事就是 `/new` 和 `/export-story`——**不丢书、不崩盘是引流的底线**。

1. 修 P1×2（润色 12000 字截断丢章节；`offerForks` 未接 rejection）——方案见 `docs/audit-0.4.13.md`
2. 顺手 P2：`command/done` 补 `commandId`、`sessionTitle.rename` 降级、只 reveal 一次
3. 录 15 秒 demo GIF（`/new` → 点界 → 启程 → 第一段 → 【歧路】→ `/export-story`），挂 README 顶部
4. 按发布节奏闭环：测 → bundle → 锁步 bump → CHANGELOG → tag → release
5. 顺手把 0.5.0 排进 backlog（缓存、shape 校验、测试 90+）

## 第三阶段：内容营销（真正的增长引擎）

核心素材三件套：**demo GIF / 开书九宫格截图 / 誊出的「天书」样章**。所有帖子都必须落到「装一行 + 星标」两个动作。

### 国内（主战场，中文用户吃网文梗）

**小红书（3 篇矩阵，错开发）**
1. 《我给 AI 装了个网文插件，它一开口就是正文》——教程向 + 界图截图；钩子：「没有欢迎语，没有『作为 AI 我建议你』」
2. 《一分钟开一本无限流》——流程动图：点界→点人→启程→第一段；钩子：「十九扇门，点哪扇活哪种命」
3. 《把和 AI 的对话誊成了小说》——贴《云中剑雨》或新誊样章第一章；钩子：成品即传播物
标签：`#DeepSeek` `#AI写作` `#网文` `#AI工具`

**B站 / 抖音：竖屏 30–60 秒演示视频**（分镜脚本）
- 0–5s 钩子：「你以为 DeepSeek 只会写代码？」
- 5–20s 开书流程特写（界图卡片是视觉担当）
- 20–40s 正文第一段配音朗读 + 【歧路】三择弹出
- 40–50s `/export-story` 誊书落盘
- 50–60s 收尾：安装一行命令 + 「点个 Star，下个界你点单」

**即刻**：短帖「一会话，一扇门，一界命数」+ 三张图，评论区置顶安装命令。
**V2EX**：创造者节点真诚向发布帖（为什么做、踩了哪些 DSH 的坑、审计里发现的怪问题当谈资）。
**微博**：带 `#DeepSeek` `#DSH` `#诸天万界`，About 那句当文案。

### 国外

**Reddit r/DeepSeek**：Show 帖——「I turned DSH into a wuxia novel engine. One session = one book.」+ GIF + 一行安装命令。
**X**：About 短句当推文 + 界图九宫格。
**awesome 合并后**：在 dsh-market 详情页出现时，第一时间补截图、回应评论区。

### 内容钩子库（每篇帖可复用）

- **深海实验室**（鲸鱼娘 / 梁圣 / 算力潮汐）：圈内梗自带话题，是「这个作者有脑洞」的证明，海外还能蹭 whale 梗
- **十九扇门**：数字钩子，让人想数一遍
- **三键「启程」**：仪式感钩子
- **誊出的天书**：可晒成品，读者转发的理由
- **不助手不提纲只写正文**：反差钩子（对比「作为 AI 我建议你」）

## 第四阶段：社区与飞轮（流量落地）

1. GitHub issue 模板 + **「点单新界」** label：用户投票下个题材，投票即参与感
2. 展示墙：README 挂「用户誊出的天书」精选（授权后），晒书是增长飞轮的燃料
3. 节奏：每 1–2 周一个版本 + 一篇内容帖，交替打
4. 题材扩军候选（每版本 +1 界，保持脑洞供给）：洪荒、诡异复苏、克苏鲁、美食、大宋市井、港风、赛博修仙、无限流 2.0、规则怪谈 2.0……
